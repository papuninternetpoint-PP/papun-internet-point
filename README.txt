PAPUN INTERNET POINT - REFERENCE MATCH WEBSITE
1. Extract this ZIP.
2. Open index.html in Chrome/Edge to preview.
3. Replace +91 9439XXXXXX in index.html with your real phone number.
4. In script.js replace 919439XXXXXX with your WhatsApp number (digits only, include 91).
5. Edit service names in index.html; colours/layout in style.css.
6. To publish free with GitHub Pages: upload index.html, style.css, script.js and hero-reference.jpg to the repository root. Then Settings > Pages > Deploy from a branch > main > /(root) > Save.

This version uses a crop of the reference screenshot as the hero banner to closely match the supplied design. Other sections are editable HTML/CSS. Search and mobile navigation work. Login, registration, application status, payment and enquiry submission require a secure backend and are not live features yet. Do not collect Aadhaar/PAN documents or passwords through this demo.
